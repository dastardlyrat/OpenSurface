# License Boundaries

OpenSurface does not silently assign one license to sources with different
recorded license states.

- `Camera Obscura/Guided Detail` retains its included MIT license and
  third-party notice.
- `Camera Obscura/Stabilized Detail Cache` retains its existing project-source
  status; no new public license is asserted here.
- `Camera Obscura/Lazara Color Revival` is derived from the project-owned
  Lazara source, whose source repository records that no project-wide license
  has yet been assigned.
- ReShade and `ReShade.fxh` are external dependencies and are not bundled.

A repository-wide license should be added only through an explicit owner
decision that accounts for each component.
