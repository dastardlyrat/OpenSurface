# License Continuation

OpenSurface publishes original software under the MIT License while preserving
the authorship, source revision, and notices carried by each admitted project.

- **Guided Detail:** continues its existing MIT grant and original
  `OpenSurface Camera Obscura contributors` notice.
- **Stabilized Detail Cache:** project-owned source is now expressly published
  under MIT by owner direction, with its package provenance retained.
- **External Image Denoiser:** project-owned standalone denoiser source is
  expressly published under MIT, with the accepted V2.1 package hash and
  denoiser-only boundary retained.
- **Lazara Color Revival:** project-owned Lazara source is now expressly
  published under MIT by owner direction. The renamed refactor preserves the
  source repository and revision in the provenance ledger.
- **xOSG — relocated:** the existing MIT grant and attribution continue in the
  [migrated family](https://github.com/alia-june/xOSG-prototype/tree/main/docs/xosg). Its license and original
  notices were carried forward; the current xOSG working tree is no longer here.
- **ReShade:** external dependency, not bundled. Its own licenses continue to
  govern it.
- **Documentation screenshots:** excluded from the MIT software grant because
  they may contain third-party game imagery. Guided Detail and Lazara images
  use `LicenseRef-Documentation-Screenshot`.

Canonical license texts are stored under `LICENSES/`. `REUSE.toml` supplies
machine-readable annotations for documentation and other files that cannot
carry inline comments. Active source also carries inline SPDX metadata so that
license and authorship survive individual-file redistribution.
