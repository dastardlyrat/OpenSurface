# Naked Shell

Naked Shell is the OpenSurface natural-language command-line universal shell.

Its purpose is to make command-line work accessible through natural language
without hiding the commands, authority, effects, or recovery path that actually
govern execution.

Current truth state: project identity and publication family accepted. No shell
implementation, parser, command grammar, execution model, platform adapter, or
security authority is claimed by this folder yet.

Future Naked Shell work belongs here rather than inside Camera Obscura. Original
software published here continues under the repository MIT license unless a
file carries a different SPDX license expression.
