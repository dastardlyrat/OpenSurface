# Authorship

## Project authorship

- **dastardlyrat**: project originator, owner direction, effect design,
  validation decisions, visual testing, and publication authority.
- **OpenSurface contributors**: implementation and documentation contributions
  recorded in repository history.
- **OpenSurface Camera Obscura contributors**: authorship identity retained from
  the Guided Detail MIT license and source repository.

Git history records individual contribution authorship. Source repositories,
commits, package hashes, refactor boundaries, and evidence states are recorded
in `docs/PROVENANCE.md`.

Authorship credit and copyright licensing are related but distinct. The MIT
grant permits broad reuse while requiring preservation of its copyright and
permission notice.
